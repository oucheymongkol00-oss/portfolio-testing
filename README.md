# Next.js Portfolio (Scaffold)

This is a simple, responsive Next.js portfolio scaffold with components for a hero, skills, projects, and contact section. Update the content in `data/projects.js` and the components under `components/`.

Get started locally:

```bash
cd code
npm install
npm run dev
```

Open http://localhost:3000

Tips:
- Edit your name and bio in `components/Hero.js` usage inside `pages/index.js`.
- Add or edit projects in `data/projects.js`.
- Replace `public/avatar-placeholder.svg` with your photo (same filename).

Personalization & deploy tips:
- To add project detail pages, add a `slug`, `longDesc`, and `images` to an entry in `data/projects.js`.
- Deploy to Vercel for zero-config Next.js hosting: connect the repo and push to Git.
- Run `npm run build` then `npm start` for production locally.
